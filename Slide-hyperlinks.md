## Selection advice

Use the main examples as supporting evidence. Keep most links in speaker notes and open them only when they help answer a follow-up. Keep the SQL-injection comic already on slide 6; it is memorable, while the search implementation supplies the technical evidence.

For the main talk, prioritize the dictionary lookup, query/projection, pagination, cache wrapper, invalidation test, and background-worker example. The ownership test is a strong backup for task 4. Reusing one coherent feature makes it easier to explain how query, cache, access rules, and tests fit together.

The Mircea presentation and Keep placeholders refer to material outside the project examples reviewed here; no exact replacement link is asserted for those personal sources.
